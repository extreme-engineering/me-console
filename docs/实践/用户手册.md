# MeOS 用户手册

> 面向使用者的逐板块操作说明。产品能力总览见[根 README](../../README.md)，架构与数据模型见 [DESIGN.md](../../DESIGN.md)。

- **适合谁**：想用一套系统管好「方向 → 行动 → 认知 → 反思 → 资源」的人；第一次打开 MeOS 的用户从「快速上手」开始即可。
- **怎么读**：第 1、2 节覆盖 90% 的日常使用；第 3 节按板块速查；第 5 节是完整功能清单。

---

## 1. 快速上手（5 分钟）

1. **打开 MeOS**：云端用户直接访问站点登录；本地用户按 [GETTING_STARTED.md](../../GETTING_STARTED.md) 启动。
2. **跟着使用向导填关键问题**（见下节）：首页会出现吊顶横幅，点「继续填写」开始。
3. **每天打开 Today 工作台**（首页）：看待办、打卡习惯、写反思，一站式完成。
4. **每周末做一次周期复盘**：反思板块 → 周期复盘 → 新建本周复盘，系统自动汇总数据。
5. **想让 AI 介入**：配置 MeLog 技能的 LLM 端点，或在任意 MCP 客户端里接入 MeOS 的 MCP Server。

**一天的推荐节奏**：早上在 Today 看今日待办 → 白天随手打卡、加待办 → 晚上写每日反思（自动带出当天数据）→「明日计划」一键生成明天待办。

## 2. 使用向导

第一次使用时，15 个「关键问题」决定了系统能不能真正帮到你：愿景是什么、有哪些领域、今天做什么……使用向导帮你把它们逐个填完。

**入口（吊顶横幅）**：打开首页（Today），顶部有横幅「使用向导 · 还有 N 个关键问题待完善」，显示总进度（如 已完成 9/15 · 60%）。点 **继续填写** 进入，点 ✕ 则本次会话不再显示（关掉浏览器标签后下次会重新出现，直到全部填完）。

**分步引导**：横幅内点击「继续填写」后：

- 每屏一个关键问题，显示所属模块、问题本身和「为什么要填」；
- **下一步 / 上一步** 逐步走，可以来回；
- **跳过**：暂时不想回答的问题可跳过（标记为「已跳过」，之后随时取消）；跳过后停留在当前步，确认状态再走；
- **去填写**：直接跳到对应板块的录入页面（会关掉向导）；
- **查看总览**：右上角随时切换到总览，一眼看到全部 15 个问题的状态 —— 已填写（绿色，显示已录入条数）/ 待填写（黄色）/ 已跳过（灰色），每一行都能直接「去填写」或「跳过」。

**进度怎么算**：某一步只要录入了至少一条数据就算「已填写」；全部填完后向导显示完成页，横幅自动消失。部分步骤与数据模式相关（如品牌板块仅云端/Fastify 模式可用，本地 IndexedDB 模式自动隐藏），无法使用的步骤不计入进度。

> 提示：向导只是起步引导。任何一步都可以先跳过，之后从各板块页面正常录入，横幅进度会随之更新。

## 3. 逐板块使用说明

### Today（`/`）— 今日工作台

- **今日待办**：看板式管理，底部输入框快速添加；紧急 / 高 / 中 / 低 四级优先级。
- **习惯打卡**：今日应打卡的习惯一键完成。
- **一键写反思**：直达每日反思。
- 顶部横幅即[使用向导](#2-使用向导)入口。

### 方向 Direction（`/direction`）— 我要去哪里

| 标签页 | 用法 |
|---|---|
| 愿景 | 写下 3-5 年想成为的人；首页会展示这段愿景提醒你 |
| 领域 | 划分人生领域（建议 5-8 个），是目标分类与平衡轮的基础 |
| 目标 | 目标 + 关键结果（OKR）；关键结果完成率自动计算，待办可关联到目标 |
| 工作流 | 画布式节点编排（可视化工作流） |
| 心态 | 心态格言，随系统出现给你提醒 |
| 平衡轮 | 八维度人生体检：按各领域目标完成率自动打分，找出生活短板 |

**三步搭好方向系统**：

1. 先写**愿景** —— 一段 3-5 年后的自我描述，写完它会出现在首页提醒你；
2. 把人生切成 5-8 个**领域**（如 事业 / 健康 / 家庭 / 学习 / 财务）；
3. 每个领域立 1-2 个**目标**，目标下拆 1-3 条**关键结果**（KR）—— KR 完成率自动累计到目标，进而决定平衡轮得分。

平衡轮不需要手动打分：它是八个领域目标完成率的可视化体检，哪里掉队一眼可见。

### 行动 Action（`/action`）— 我今天做什么

- **待办**：完整看板；支持优先级、关联目标。
- **习惯**：习惯列表 + 打卡日历，连击与完成率累计。
- **健康记录**：体重、血压等身体数据也在本页录入；会自动带入每日反思。

推荐节奏：想到什么先丢进待办（收集），早上挑出今天要做的放进 Today，能支撑 KR 的就关联到对应目标 —— 这样目标完成率和平衡轮才有数据可算。

### 认知 Cognition（`/cognition`）— 我要搞懂什么

- **课题**：正在钻研的主题，每个课题下追加进展笔记，零散想法收拢成线。
- **洞察**：值得记录的想法或顿悟；建议写清触发场景与应用场景。
- **阅读**：在读 / 想读的书与文章，状态流转（想读 → 在读 → 读完），读完沉淀到认知库。

建议的流转：零散想法先记**洞察** → 同类想法多了就升级为**课题**持续钻研 → 相关书籍丢进**阅读**清单，读完把要点沉淀回洞察。

### 反思 Reflection（`/reflection`）— 我做得怎样

- **每日反思**：按固定小节记录（庆祝 / 改进 / 明日计划 / 心情）；系统自动汇总当天的待办、习惯与健康数据。「明日计划」可一键生成明天的待办。
- **周期复盘**：周 / 月 / 季 / 年四个周期；新建复盘时自动汇总该周期的目标、待办、习惯数据；MeLog「生活复盘」技能生成的报告也会同步为这里的草稿。

### 资源 Resources（`/resources`）— 我用什么做

- **订阅**：记录订阅服务与费用；配额管理（次数 / 额度）、月度用量追踪，用量仪表盘帮你发现闲置浪费。例如给「AI 助手」设每月 100 次配额，每用一次记一笔，月底直接看用量 vs 配额。
- **人脉**：联系人档案与触达记录，长期未联系会被提醒。
- **健康**：身体数据记录（与行动板块同数据）。
- **开发环境**：登记你的开发环境信息。

### MeLog（`/melog`）— 我的生活数据说了什么

- **时间线**：健康、笔记、聊天记录等汇入的统一生活流水；全文搜索（支持中文）。
- **数据源**：管理连接器接入；聊天记录等敏感分类默认不上云（数据分层边界）。
- **技能**：内置规则技能 + LLM 技能（接自己的 OpenAI 兼容端点生成生活报告）；支持定时调度（每天 / 固定间隔），报告可自动同步为周期复盘草稿。
- **标准 / MCP**：MeLog Standard 开放数据信封规范；任何 MCP 客户端可读写时间线、运行技能。

连接器（Apple 健康 / 聊天记录导出 / 滴答清单 / 口述等）的安装与令牌管理见 [packages/connectors/README.md](../../packages/connectors/README.md)。

**接入你的生活数据（5 步）**：

1. 在 MeLog「数据源」页创建数据源，生成 `melt_` 连接器令牌（明文只显示一次，请立即保存；令牌可绑定单一数据源、随时独立吊销）；
2. 安装连接器 CLI（见连接器指南）；
3. 用令牌运行对应连接器，导入健康 / 笔记 / 聊天记录 / 任务数据；
4. 回到时间线用全文搜索验证（支持中文）；
5. 需要自动化时配置技能与定时调度 —— 如每晚 23:00 用 LLM 技能生成一周生活报告，自动同步为周期复盘草稿。

**让 AI 客户端读写你的时间线（MCP）**：MeLog 内置 JSON-RPC 2.0 的 MCP 端点（`POST /mcp`，登录 JWT 鉴权），提供 4 个工具 —— `melog_get_overview`（数据源概览）、`melog_query_entries`（查询时间线）、`melog_ingest_entries`（写入数据）、`melog_run_skill`（运行技能）。在任意 MCP 客户端里把端点指向 `/mcp` 后，先发一次 `tools/list` 查看工具清单：

```json
{"jsonrpc":"2.0","id":1,"method":"tools/list"}
```

### 品牌 Brand（`/brand`）— 我的输出如何影响世界

- **总览**：品牌板块驾驶舱。
- **档案**：品牌资产中枢 —— 定位、受众、内容支柱（使用向导中的「品牌蓝本」一步即此处）。
- **流水线**：「一鱼多吃」—— 一篇素材拆成多平台内容，逐平台追踪分发状态。
- **渠道**：平台渠道矩阵与指标快照。
- **作品**：作品库；**分析**：指标趋势分析。

### Workbench（`/workbench`）

个人工作台聚合页，适合作为日常第二入口。

## 4. 数据与隐私

| 模式 | 数据在哪 | 适合 |
|---|---|---|
| 云端（默认） | Meoo 云 PostgreSQL，RLS 行级隔离 | 日常多设备使用 |
| 本地 IndexedDB | 仅此浏览器，零服务器 | 隐私 / 离线 |
| 本地 SQLite（Fastify） | 本机文件，可脚本备份 | 开发 / 完全自托管 |

- 聊天记录等敏感分类的数据**默认不进入云端**，即使接了云同步也留在本地。
- 本机 SQLite 可用 `./scripts/backup-db.sh` 备份（保留最近 30 份）。

### 手机上怎么用

- **云端模式**：手机浏览器打开站点登录即用，数据与桌面一致；可「添加到主屏幕」当 App 用。
- **本地 IndexedDB 模式**：数据只在当前浏览器里，换设备不会同步。
- 敏感分类（聊天记录等）本来就不上云，所以任何设备端都不会看到它们出现在云端。

## 6. 常见问题

- **跳过的问题以后还能填吗？** 可以。从总览「取消跳过」，或直接去对应板块录入，状态会自动变回「已填写」。
- **横幅关掉了还会出现吗？** 点 ✕ 只在当前浏览器会话隐藏；重开标签页会再出现，直到 15 个问题全部处理完（填完或跳过）。
- **某一步没有出现在向导里？** 该步骤在当前数据模式不可用（如品牌板块在本地 IndexedDB 模式），或接口暂时不可用 —— 向导宁可少一步也不会卡死。
- **手机上能用吗？** 能。云端模式用手机浏览器登录即可，录入与阅读和桌面一致。
- **怎么让 ChatGPT / Claude 等 AI 客户端接入？** 通过 MeLog 的 MCP 端点，见第 3 节「让 AI 客户端读写你的时间线」。
- **云端数据怎么备份？** 日常安全由 Meoo 平台托管；管理员可用 `meoo db query` 逐表导出 JSON（见 [README 数据备份](../../README.md#数据备份)）。
- **本地 dev 登录 403？** 见 [README 常见问题](../../README.md#常见问题)。
